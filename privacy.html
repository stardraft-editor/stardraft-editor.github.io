StarDraft 2

Privacy

Last updated 2026-10-14

StarDraft 2 has no accounts, no ads, no analytics and no tracking. It sends something to the developers only when you choose to: feedback that you write, and crash reports that you allow. Both are posted without your name as public issues on GitHub.

Feedback

You can send feedback from the program (Help > Report feedback, the feedback button, or right-click > Report feedback). Nothing is sent until you press Send. It is sent without your name, email or account. It contains:

  • the text you write
  • what you gave feedback on (for example a list item or window title, which can be a name from your map)
  • the workspace, the StarDraft 2 version and the Windows version

It becomes a public issue on GitHub that anyone can read, so do not write sensitive or private information in it. Until it is sent, it is kept in %LOCALAPPDATA%\StarDraft\feedback, which also keeps a list of the feedback you sent.

Crash reports

When StarDraft 2 crashes, it writes a crash report on your computer, in %LOCALAPPDATA%\StarDraft\crashes. It sends a report only if you allow it: at the next start it asks (Send, Always send, Do not send). You can change this at any time in File > Options > Crash reports (Ask, Send, Do not send). The default is Ask.

A report that is sent has no name or account, and contains:

  • the StarDraft 2 version, the Windows version and the name of the video card
  • where it crashed (the error and the program functions it was in)
  • the last 60 lines of the program's log

It does not contain your maps. The log lines can contain file paths (which can include your Windows user name) and names from your map, such as location or unit names. The report becomes a public issue on GitHub. The crash folder also has a memory dump (crash.dmp) for debugging; StarDraft 2 does not send it.

Updates and euddraft

When "Look for updates on start" is on (File > Options; it is on by default), StarDraft 2 asks GitHub for the newest release at each start. You can also check from Help > Check for updates. An update is downloaded from GitHub only when you choose Install. The first time you build a project, StarDraft 2 downloads euddraft from GitHub. None of these send your maps or anything you wrote.

What GitHub sees

Feedback, crash reports, update checks and downloads go to GitHub, which sees your IP address, like any website you visit. GitHub's handling of it is in the GitHub Privacy Statement.

On your computer

StarDraft 2 keeps its settings, recent maps and projects in the Windows registry (HKEY_CURRENT_USER\Software\StarDraft) and its files in %LOCALAPPDATA%\StarDraft. They stay on your computer. You can delete them.

This website

This website sets no cookies of its own and has no analytics. It is hosted on GitHub Pages and uses Google Fonts, a YouTube video (youtube-nocookie.com, loaded when you scroll to it) and GitHub's API for the newest release; these services see your IP address. Your language choice on the main page (EN | KR) is kept in your browser.

Removing a report, and questions

If you sent something that you want removed, or have a question about privacy, write on Discord or open an issue on GitHub, with the link to the issue, and we will remove it.

Changes

When StarDraft 2 changes what it sends, this page changes with it, with a new date.

StarDraft 2 is not associated with Blizzard Entertainment. It needs an installation of StarCraft to work.
